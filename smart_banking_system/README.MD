## 💼 Case Study: Smart Bank Management System

I am building a simple simulation of a smart banking system that handles different types of users (customers, admins), various account types (savings, current), and transaction behaviors like deposits, withdrawals, transfers, and account history.

### 🎯 Objectives:
    
 * Design a system using classes and inheritance.

 * Implement encapsulation to protect sensitive data (e.g., balances).

 * Use abstraction for core banking actions (via abstract base classes).

 * Apply polymorphism in transaction behavior or account statements.
